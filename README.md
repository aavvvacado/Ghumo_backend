**Ghumo Backend** is a scalable, low-latency travel discovery and AI itinerary generation engine. Built with FastAPI, Supabase PostgreSQL, Valkey/Redis hot caching, Celery workers, and Google Gemini 1.5 AI, Ghumo delivers sub-200ms search responses, real-time Server-Sent Events (SSE) progress streaming, place quality validation, and real place image resolution.

Documentation: [https://aavvvacado.github.io/Ghumo_backend/](https://aavvvacado.github.io/Ghumo_backend/)

---

## Key Features & Innovations

### 1. PostgreSQL-First Storage Engine
- **Single Source of Truth**: All valid places, AI context, search metrics (`search_count`, `last_searched_at`, `normalized_name`), and community feedback are permanently persisted in Supabase PostgreSQL.
- **Selective Hot Caching**: Valkey (Redis) caches search queries **only** when search frequency meets `CACHE_SEARCH_THRESHOLD` (default: 3 searches).
- **Fast Spatial & Name Indexing**: Indexed with `idx_place_norm_city` composite index for instant deduplicated lookups.

### 2. Place Quality Validator
- **Pre & Post Validation**: Intercepts place items before enrichment and persistence to discard generic/placeholder names (`unknown`, `n/a`, `point of interest`, `null`).
- **Coordinate Integrity**: Validates geographic bounds and rejects zero-coordinate `(0.0, 0.0)` anomalies.
- **Canonical Normalization**: Standardizes place names (lowercase, punctuation stripped) to eliminate duplicates.

### 3. Place & Itinerary Image Resolution Engine
- **Zero AI Hallucinations**: Image URLs are strictly resolved via real external providers, never generated by the LLM.
- **Multi-Provider Fallback**:
  1. **Wikimedia Commons / Wikidata**: Primary free provider for exact place and city matching.
  2. **Unsplash API**: High-resolution fallback.
  3. **Google Places API**: Optional fallback.
- **7-Day Image Caching**: Resolved image metadata is cached in Valkey for 7 days.

### 4. Community Feedback Loop (1–5 Stars)
- **Single-Rating Constraint**: Enforces one active rating per user per target using `TargetFeedback` unique constraint (`user_id_or_anon`, `target_type`, `target_id`). Re-submitting a vote updates existing feedback.
- **Bayesian Confidence Score**: Computes weighted rating scores:

$$W = \frac{v}{v + m} R + \frac{m}{v + m} C$$

- **Seamless API Integration**: Exposes a backward-compatible `feedback` object (`averageRating`, `ratingCount`, `weightedScore`) on place responses.

## API Reference Overview

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `/search` | `GET` | Sub-200ms intelligence search with background Celery enrichment |
| `/search/stream` | `GET/POST` | SSE real-time streaming endpoint for search progress |
| `/suggestions` | `GET` | Hot/trending places with verified image URLs & ratings |
| `/target-feedback` | `POST` | Submit or update 1-5 star user ratings for places/itineraries |
| `/itinerary` | `POST` | Day-by-day AI travel itinerary generator |
| `/itinerary/stream` | `POST` | SSE streaming endpoint for itinerary generation |
| `/itinerary/video` | `POST` | Extracts places & itineraries from YouTube video URLs |
| `/nearby` | `GET` | Radius-based geographic place search (`lat`, `lng`, `radius`) |
| `/hidden-gems` | `GET` | Offbeat place recommendations |
| `/tips` | `GET` | Travel tips by place ID or city |
| `/health` | `GET` | System health check (PostgreSQL + Valkey status) |

## Quickstart & Local Setup

### 1. Prerequisites
- Python 3.11+
- Redis / Valkey server
- PostgreSQL database (or Supabase instance)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/aavvvacado/Ghumo_backend.git
cd Ghumo_backend

# Create and activate virtual environment
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Environment Configuration (`.env`)
Create a `.env` file in the root directory:
```env
DATABASE_URL=postgresql://postgres:[PASSWORD]@db.[REF].supabase.co:5432/postgres
VALKEY_URL=redis://localhost:6379
GEMINI_API_KEY=your_gemini_api_key
UNSPLASH_ACCESS_KEY=your_unsplash_access_key
GOOGLE_PLACES_API_KEY=your_google_places_key
CACHE_SEARCH_THRESHOLD=3
CACHE_TTL_SECONDS=604800
MIN_FEEDBACK_COUNT=5
```

### 4. Run Development Server
```bash
uvicorn app.main:app --reload --port 8000
```

### 5. Run Celery Worker
```bash
celery -A app.celery_app worker --loglevel=info --pool=solo
```

### 6. Run Unit Tests
```bash
python -m pytest
```
